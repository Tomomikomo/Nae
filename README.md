# Nae Gallery

A lightweight local gallery for Android. Developed entirely on mobile devices using Sketchware Pro (utilizing pure Java classes).

# Tech Stack

* **Language:** Java & Kotlin
* **Platform:** Android
* **Development Environment:** Sketchware Pro (Add Source Directly / Custom Classes)

# Architecture Note

This project was developed entirely on mobile devices (finalized on a tablet) due to the temporary absence of a PC. It stands as a proof of concept that complex media handling, thumbnail caching, and fluid UI rendering can be successfully implemented under strict mobile hardware limitations. Interestingly, this lightweight approach bypasses the bloated configuration files and Gradle dependency hell of standard PC IDEs, where compilation errors and environment conflicts often trigger unexpected build failures.
